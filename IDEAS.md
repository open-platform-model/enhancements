# Ideas

One line per idea that is not an enhancement yet.

This file exists so that the admission rubric has somewhere to send what it declines. Without it, the `feature` gate would just be friction: an idea with nowhere to go gets filed as a draft anyway, and a draft is eight documents with a lifecycle attached — which is exactly how a design repo turns into a scratchpad.

**A line here has no structure in it to rot.** That is the whole point. There is no template, no status, no id, no validation, and nothing to keep up to date. An idea can sit here for a year and still be exactly as true as the day it was written.

## How to use it

- **Add a line** whenever an idea is worth not losing but cannot yet answer "what capability will OPM have that it does not today?".
- **Promote a line** by running the creation gates and `task new`; delete the line in the same commit.
- **Delete a line** when it stops being interesting. No ceremony, no tombstone — nothing cites these, which is the difference between this file and an entry.

If a line grows into a paragraph, that is the signal it wants to be an entry. Run `task gate ID=` after scaffolding, not before: the rubric is what decides.
